# Updated API Contracts

The authoritative OpenAPI 3.x specification is generated by `scripts/generate-openapi.py` into [`api/openapi/openapi.json`](../../api/openapi/openapi.json) and served live at `GET /api/openapi.json` (**178 paths**).

## Global Conventions
- **Authentication:** `Authorization: Bearer <opaque-token>` on all protected routes. Web clients use HttpOnly `SameSite=Strict` refresh cookie (`spartial_refresh`, path `/api/v1/auth`) and require configured `Origin`. Mobile clients receive/send `refresh_token` in JSON and must not send `Origin`.
- **MFA Login Contract:** `POST /api/v1/auth/login` returns either session tokens (`200`) or `{"mfa_required": true, "challenge_token": "...", "expires_in": 300}` (`200`). Client exchanges the challenge via `POST /api/v1/auth/mfa/verify` with either `code` (6-digit TOTP) or `recovery_code`.
- **Idempotency:** Create/payment/dispense endpoints require `Idempotency-Key` (8–128 chars; UUID for `pharmacy.dispense` and `billing.payment`). Replays with the same payload return the original response; payload mismatch returns `409 idempotency_conflict`.
- **Optimistic Locking:** Mutable resources expose `version` (mapped from `row_version`) and require `version` on update/state transitions; stale versions return `409 conflict`.
- **Error Envelope:** `{"error": {"code": "...", "message": "...", "fields": {...}}, "request_id": "..."}` with `X-Request-ID` header.
- **SQLSTATE Mapping:**
  - `SPT01`, `SPI01`, `SPS01`, `SPB01` -> `409 conflict` (user-facing database rule message)
  - `23505`, `23P01`, `40001`, `40P01` -> `409 conflict`
  - `SPV01`, `SPC01`, `SPX01` -> `422 rule_violation`
  - `23503`, `23514`, `22P02` -> `422 invalid_reference`
  - `SPA01`, `42501` -> `403 forbidden`
  - `28000` -> `401 unauthorized`
- **Permission Aliases:** `GET /api/v1/auth/me` emits both `spartial_hms` permissions (`patient.read`, `admin.user.manage`, `audit.read`, etc.) and backwards-compatible frontend aliases (`patients.read`, `patients.write`, `facilities.read`, `facilities.manage`, `staff.read`, `staff.manage`, `metrics.read`, `privacy.report`, `break_glass.request`, `break_glass.review`, `approvals.request`, `approvals.review`).
