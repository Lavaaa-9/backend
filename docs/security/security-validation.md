# Security Validation

## Cryptographic & Authentication Controls
- **Passwords:** Argon2id PHC hashes verified with constant-time comparison and common-password denylist (`internal/security/password_policy.go`). Password changes and resets append to `iam.password_history` and revoke all active sessions. Password reset requests are non-enumerating (`202 Accepted`).
- **Session & Refresh Tokens:** 256-bit random opaque tokens; only SHA-256 digests (`bytea`, 32 bytes) are persisted. Sliding idle timeout and absolute max lifetime are enforced inside `sec.begin_request()`. Refresh token rotation detects token reuse and revokes the entire session family.
- **MFA (TOTP + Recovery Codes):** RFC 6238 TOTP (SHA-1, 30s step, 6 digits, ±1 skew) with monotonic `last_used_step` replay protection (`iam.mfa_factor`), 5-attempt/5-minute login challenges (`iam.mfa_challenge`), and 10 single-use 80-bit recovery codes (`iam.mfa_recovery_code`). `MFA_ENFORCE_PRIVILEGED` and `MFA_ENFORCE_REMOTE_CLINICAL` are forced `true` in production.
- **Field-Level Encryption & Blind Indexing:** AES-256-GCM keyring (`internal/security/keyring.go`) with per-entity AADs (`iam_mfa_factor:<uid>`, `patient_identifier:<org>:<pid>:<type>`, `billing_coverage:<org>:<pid>:<payer>`, `comms_device:<uid>`, `document:<org>:<doc>`) and independent 32-byte HMAC-SHA256 `IDENTIFIER_INDEX_KEY` blind indexes. Ciphertexts and blind indexes are stripped from all API JSON responses; decryption requires explicit `patient.identifier.reveal` permission and a mandatory audited `reason`.
- **Key Rotation:** Supported live without downtime via multi-key `PHI_ENCRYPTION_KEYS` + `go run ./cmd/manage rotate-keys`.
- **Four-Eyes Separation of Duties:** Enforced in SQL triggers/constraints on `billing.refund`, `billing.cashier_shift` reconciliation, `diag.result` verification, `iam.break_glass_access` review, `gov.approval_request`, and `iam.membership_role` self-grant prevention.
- **PHI Redaction:** Structured JSON HTTP logs record only `request_id`, `method`, `route`, `status`, and `duration_ms`. Production error handler omits internal error causes. Migration reconciliation reports emit only table names, UUIDs, and reason codes.
