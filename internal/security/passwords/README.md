# Offline common-password screen

common.txt is SecLists' 10k-most-common.txt, pinned to commit 913b327317496d062bcc7cace524aaad8a693be2 under its MIT license (LICENSE).
Source: https://github.com/danielmiessler/SecLists/blob/913b327317496d062bcc7cace524aaad8a693be2/Passwords/Common-Credentials/10k-most-common.txt
SHA-256: 68782d6a4a19a4768d5f15dd66bd534e7a33055cc755411e33f16d18c50fdcce.

supplemental.txt contains local illustrative weak phrases/sequences not present in that upstream file. Matching is case-insensitive and trims surrounding whitespace for screening; actual accepted password bytes are hashed unchanged. No candidate passwords are sent to a network service. This is a limited common-password screen, not proof that a password has never been breached. Update this list under review as part of security maintenance.
